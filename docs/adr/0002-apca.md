# ADR 0002 · Including APCA contrast

**Date:** 28 Oct 2026 · **Status:** Accepted · **Decided by:** Benji Greig · **Plane:** CLR-6, CLR-58 · **Decision log:** D-013

## Decision

- The engine defines an interface for contrast models and ships **WCAG 2** itself, under Apache 2.0.
- **APCA** comes through a separate add-on that depends on the **unmodified official `apca-w3` package**, kept under its own licence, with a clear notice in the add-on and in `NOTICE`.
- We don't use the APCA logo. The plain-text name "APCA" labels only the correct, current implementation.
- We email Myndex Research to ask for written confirmation of this use and of the name (CLR-58). Launch doesn't wait for a reply. If they object, the add-on is removed without changing the engine.

## Context

APCA is central to colouri.st (D-006). Before building on it, we read its licence.

**Sources, read 28 Oct 2026:**

- [apca-w3 LICENSE.md](https://github.com/Myndex/apca-w3/blob/master/LICENSE.md)
- [apca-w3 README](https://github.com/Myndex/apca-w3)
- npm `apca-w3` 0.1.9: licence field "Limited W3 License"; last published July 2022

**What the licence says:**

- **Scope:** licensed to the W3/AGWG for web-delivered and web-based content only. It isn't an open-source licence and can't be relicensed under Apache 2.0.
- **Modifications:** use is allowed only without modifying the essential elements of the code or the approved constants. Changes are allowed only to port it to another language. An implementation that doesn't match the approved algorithm is treated as a breach.
- **Currency:** developers must use the most recent version.
- **Commercial use** needs a separate signed agreement. colouri.st is free and for web content, so it fits the permitted use.
- **Name and trademarks:** "APCA" may be used only for correct, current implementations. Using the logo or trademarks needs written consent.
- **Revocation:** a licence for use is revoked when an asset is removed from the repository.

## Alternatives

- **Write our own APCA,** in line with our reference-not-reuse principle (D-008). Rejected: the licence forbids modified implementations.
- **Leave APCA out of the beta.** Rejected by D-006.
- **Find an alternative perceptual contrast model.** Kept as the fallback if Myndex objects.

## Consequences

- This is the one exception to D-008.
- The add-on must track the latest `apca-w3` release, and its version is pinned and reviewed on each update.
- The interface labels results as "APCA" only when the add-on is present and current.
- If the licence changes or the add-on is removed, the tool falls back to WCAG 2 alone, and the guided flow's explanation adapts.
